What's new

What's new in 0.4.0

0.4.0 is the UI overhaul: a new design, about 115 bugs fixed, faster requests and history, saving in the background, and safer Git.

The redesign
One calm surface
Underline tabs, one URL field with the method inside it, and the response status, time and size in the tab bar. Loading and error states have a Retry button.
Settings as a page
Eight themes as preview cards, plus General, Network & TLS, Git, Shortcuts and About. The command palette groups open tabs, saved requests, history and commands.
Speed
Opening requests and history
Opening a request or a history entry took 1–3 s. It now takes a few milliseconds.
Saving in the background
With a 5 MB request open, autosave froze the window for about 0.1 s. It now takes about 1 ms, and quitting writes the latest changes first.
Fixes and safety
About 115 bugs fixed
From cURL paste, Windows cmd and PowerShell copies included, and compressed responses to Postman import, drag and drop, and settings that reset on restart.
Safer Git
Tokens and passwords stay out of commits and are kept locally. Switching branches with uncommitted changes asks first, and a pull, branch switch or restore no longer throws away your edits.
rustman-cli run
New
Sends a collection's requests from a terminal or CI, and exits with status 1 when one fails.

Scripting

A scripting language built in Rust, not borrowed from Node.

Pre-request and test scripts run on rustman-engine, a small interpreted language written in Rust. There is no embedded JS runtime and no pm.* API to memorize. It covers env vars, headers, cookies, JWT decoding, base64 and JSON assertions, in a syntax small enough for an LLM to write correctly from a plain-English request. A pre-request script's set_env applies to the request it runs for. The grammar and built-ins are on the scripting docs page.

Pre-request script
// inject a bearer token, only if one is set
let token = env("access_token")
if token != "" {
    set_header("Authorization", "Bearer " + token)
}
Test script, post-response
// check the login, then save its token
test("status is 200", response.status == 200)

let token = response.json().token
test("has a token", token != null)
if token != null {
    set_env("user_id", jwt_decode(token).payload.sub)
}

# Requires Rust 1.88+, a C compiler and CMake
git clone https://github.com/rust-man-org/rustman
cd rustman
cargo build --release

Needs a Rust toolchain (1.88 or newer), plus a C compiler and CMake for the vendored libgit2, OpenSSL and SQLite. cargo build --release -p rustman-cli builds the command line runner. The full guide is in docs/DEVELOPMENT.md.
